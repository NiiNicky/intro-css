O que é o CSS?

O CSS sigifica Cascading Style Sheets, ou folhas de estilo em cascata.

Sobre o CSS

Linguagem responsável por definir a aparencia visual e organização dos elementos na tela.

Como aplicar o CSS?

Para o CSS, temos 3 abordagens

  • CSS Inline
  • CSS Interno
  • CSS Externo

O que da para fazer com o CSS?

O CSS não serve apenas para colocar cor na página. Ele controla:

  • cores
  • fontes
  • tamanhos
  • espaçamentos
  • sombras
  • bordas
  • posicionamentos
  • responsividade
  • animações
  • transições

Aplicando o CSS Inline

Nessa abordagem o CSS é colocado diretamente no elemento HTML ataravés do atributo style

Aplicando o CSS Interno

Nessa abordagem o CSS é aplicado dentro de uma tag < style > dentro do < head > do documento HTML.

Aplivando o CSS Externo

Nessa abordagem os estilos do CSS ficam concentrados em um arquivo separado.

Para conectar esse arquivo ao HTML utilizamos o elemento de < link > no < head > da página.
